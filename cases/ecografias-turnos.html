Sistema de Turnos — Ecografías del Sur

Recepción, consultorio y sala de espera coordinados en una red local, con actualización en tiempo real y sin depender de Internet para la operación diaria.

Node.jsExpressSQLiteWebSocketsLocal-first
Problema

Tres puntos de una misma operación debían compartir estado.

Recepción registra la llegada, el profesional llama desde su consultorio y la sala de espera debe mostrar el llamado de forma inmediata y comprensible. La solución además debía adaptarse a información proveniente de un sistema externo y funcionar con infraestructura local.

Solución

Un sistema local con tres interfaces coordinadas.

Helios / Excel
      ↓
  Importación
      ↓
    SQLite
      ↑
Express + lógica de cola
      ↓
  WebSocket
 ┌────┼─────────┐
 ↓    ↓         ↓
Recepción  Consultorio  Sala

La sala muestra el llamado y reproduce señal sonora + voz sintetizada. Las pantallas se actualizan en tiempo real y la persistencia queda local.

Decisiones

La restricción operativa definió la arquitectura.

  • Local-first: la operación diaria no depende de servicios cloud.
  • WebSockets: sincronización inmediata entre interfaces.
  • SQLite: persistencia simple para una operación acotada.
  • Excel como integración: adaptación pragmática a una fuente existente sin API.
  • Node portable: instalación Windows con baja fricción operativa.
Producción

El proyecto incluye operación y recuperación, no sólo código.

El repositorio documenta instalación, checklist, backup/restauración, operación diaria y releases. También conserva material histórico marcado como obsoleto para reducir errores de mantenimiento.

Valor del casoMostrar que una solución técnica llega hasta el entorno donde las personas efectivamente trabajan.
