# Portfolio — Mauro Montenegro

Portfolio profesional orientado a roles de **Operations, Data, Analytics, Process Improvement y Automation**.

## Enfoque

El portfolio presenta los proyectos por el problema que resuelven, no por una lista de tecnologías.

Cada caso intenta responder:

1. ¿Qué problema operativo existía?
2. ¿Qué restricciones había?
3. ¿Qué solución se diseñó?
4. ¿Qué decisiones fueron importantes?
5. ¿Qué resultado o estado verificable existe?
6. ¿Qué capacidad profesional demuestra?

## Política de privacidad

- Los casos basados en operaciones reales no exponen datos personales, credenciales, IPs, tokens ni infraestructura sensible.
- Los repositorios reales pueden permanecer privados aunque el caso se describa públicamente.
- Las demos públicas deben utilizar datos sintéticos o material preparado específicamente para portfolio.
- Las capturas de sistemas reales deben prepararse con datos ficticios o anonimizarse antes de publicarse.
